# Benjamin Ajewole MSc E-Portfolio

A responsive single-page e-portfolio built with HTML and CSS.

## Files

- `index.html`: page content and structure
- `styles.css`: layout, colours, typography and responsive design

## Customise before publishing

1. Replace the GitHub placeholder link in `index.html`.
2. Update module names and statuses to match your programme.
3. Replace each `href="#"` module link with a real page or repository URL.
4. Review role descriptions, dates and certifications.
5. Optionally replace the initials card with a professional photograph.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

GitHub will provide a public site address after deployment.
